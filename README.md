# lag-sonar

Значок в menu bar macOS, по виду которого сразу понятно, **на каком уровне**
сейчас проблема со связью.

Главный вопрос, на который он отвечает: Claude отвечает медленно — это моя сеть,
мой VPN или это у них?

## Как читать значок

**Кольцо — состояние сети. Ядро — состояние Claude.**

| кольцо | что означает |
|---|---|
| 🟢 зелёное сплошное | сеть работает |
| 🟡 янтарное с разрывом | связь есть, но DNS не резолвит имена |
| 🟣 фиолетовое | интернет есть, а VPN не пропускает трафик |
| 🟠 оранжевое | наружу не проходит ничего: провайдер или роутер |
| ⚪ серый пунктир | нет линка, Wi-Fi выключен |
| ⚪ тусклое серое | ещё не измеряли |

| ядро | что означает |
|---|---|
| ● зелёный круг | Claude отвечает нормально |
| ▲ жёлтый треугольник | Claude отвечает, но медленнее 1,5 с |
| ■ фиолетовый квадрат | до API не доходим: региональная блокировка, нужен VPN |
| ✕ красный крест | Claude не отвечает |
| ❗ красный восклицательный | у Anthropic объявлена авария |
| ○ серый контур | сети нет — о Claude судить нельзя |

Ради чего всё затевалось: **зелёное кольцо и красное ядро** означает «сеть
в порядке, проблема у них».

Клик по значку открывает расклад по слоям с измеренными задержками.

## Запуск

Требуется Python 3 с PyObjC. Установка не нужна, если PyObjC уже есть:

```bash
python3 -c "import AppKit"     # если молча — всё на месте
pip3 install pyobjc-framework-Cocoa   # если нет
```

Значок в menu bar:

```bash
python3 -m lag_sonar
```

Та же диагностика текстом, без GUI:

```bash
python3 -m lag_sonar.cli           # один замер
python3 -m lag_sonar.cli --watch   # непрерывно
```

## Автозапуск

```bash
./scripts/install-agent.sh              # запускать при входе в систему
./scripts/install-agent.sh --uninstall  # выключить
```

Журнал: `~/Library/Logs/lag-sonar.log` — туда пишутся переходы между состояниями.

## Как устроено

Различить «мою» проблему и «их» можно только измеряя обе дорожки сразу.
Приложение щупает сеть двумя путями одновременно:

- **мимо туннеля** — сокет привязывается к физическому интерфейсу
  (`IP_BOUND_IF`), так проверяется провайдер;
- **по маршруту по умолчанию** — так проверяется VPN.

| прямой канал | через VPN | вывод |
|---|---|---|
| ок | ок | сеть в порядке |
| ок | нет | виноват VPN |
| нет | нет | виноват провайдер |

Две вещи, без которых диагностика врала бы:

1. **Пробы доводятся до TLS-рукопожатия, а не до `connect()`.** VPN-клиент
   подтверждает TCP-соединение локально: на мёртвом туннеле `connect()`
   возвращается за 0,4 мс, изображая рабочую сеть.

2. **Проба Claude различает коды ответа.** Запрос без ключа даёт `401`, если
   API доступен, и `403`, если нас режут по региону. Первое — норма, второе —
   повод включить VPN.

Смена значка требует двух совпавших замеров подряд: на реальном канале
задержка гуляет от 450 мс до таймаута, и без этого значок мигал бы непрерывно.

### Модули

```
config.py     интервалы, таймауты, пороги — всё настраиваемое в одном месте
netinfo.py    топология: физический интерфейс, шлюз, активен ли VPN
probes.py     сетевые пробы, каждая со своим таймаутом
diagnosis.py  чистая функция: пробы → вердикт. Без ввода-вывода
icon.py       отрисовка значка по паре состояний. Без сети
menu.py       выпадающее меню
runner.py     расписание опроса и гистерезис
app.py        NSStatusItem, таймер, пул потоков
cli.py        тот же вердикт в терминал
```
